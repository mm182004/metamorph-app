# MetaMorph

A fast, native desktop file converter for images, audio, video, and documents. Built with Rust and Tauri.

## Features
- **Local Processing:** All conversions happen entirely on your machine. Zero cloud uploads.
- **Native Performance:** Uses hardware-accelerated engines (FFmpeg, LibreOffice, Pandoc).
- **Batch Conversion:** Drag and drop multiple files and convert them simultaneously.

## Installation
1. Go to the [Releases](../../releases) page.
2. Download the installer for your operating system:
   - **Windows:** `.exe`
   - **macOS:** `.dmg`
   - **Linux:** `.deb`
3. Install and run.

## Usage
1. Drag and drop files into the application window, or press `Ctrl+O` to browse.
2. Select a master target format at the top, or individually assign formats per file.
3. Click **Convert**. 
4. The converted files will be automatically saved in the same directory as the originals.
